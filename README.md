## Что это

Lumo помогает фотографу/видеографу находить B2B-клиентов: Discovery (ЕГРЮЛ/DaData), квалификация,
Content Audit, Lead Score, Готовность к контакту, офферы, ЛПР, outreach и повторные касания —
всё локально в браузере, без платных API.

### Автоматическое обогащение компаний (Enrichment)

«Найти контакты и соцсети» в карточке компании: официальный сайт → страница контактов →
соцсети → каталоги. Принцип: найти → оценить → предпросмотр → подтверждение → сохранить.
Данные из поисковиков считаются ненадёжными; LOW-находки не применяются автоматически;
всё проверяется открытием официального сайта.

Опциональный локальный поисковый стек (без платных API): SearXNG в Docker + helper
(`local-search/`). Недоступность стека не блокирует приложение: известные сайты обрабатываются
без единого поискового запроса, остальные сценарии завершаются понятным fail-safe
(«Поиск сейчас недоступен») без «мусорных» данных.

## Деплой (GitHub Pages)

1. Создайте репозиторий (например `Lumo`).
2. Скопируйте `index.html`, `VERSION.json`, `404.html`, `robots.txt`, `.nojekyll` и `.github/workflows/deploy.yml` в корень.
3. Settings → Pages → Source: **GitHub Actions** (workflow собирает `./` как есть).
4. Сайт: `https://<user>.github.io/Lumo/`.

`.nojekyll` обязателен. `404.html` содержит spa-fallback с учётом базового пути `/Lumo`.
`VERSION.json` не трогать руками — он генерируется `tools/make_version_meta.py` после freeze index.html.

## Локальный запуск

Просто откройте `index.html` в браузере (или `python3 -m http.server` в папке сборки).

## Реальные данные и приватность (v3.4.6)

- Публичная сборка (`index.html` в этом репозитории) **не содержит** реальных лидов и переговорной
  истории: `REAL_LEADS = []`. Первый запуск поднимает демо-набор (20 вымышленных компаний, `isDemo:true`).
- Канонический набор MASTER (10 реальных лидов) хранится **локально** в `local-data/REAL_LEADS.json`
  релизного пакета (вне публичного репозитория; см. `.gitignore`). Файл извлечён из v3.4.5 побайтово
  без изменений (round-trip проверен).
- Перенос в рабочую базу — только явный импорт: **Настройки → Данные → «Импорт лидов (добавление)»**.
  Импорт недеструктивный: существующие записи не изменяются, дубли по ID/имени пропускаются,
  счётчики показываются в предпросмотре. Автоматической миграции нет.
- Существующая база владельца (localStorage браузера) не затрагивается обновлением: сиды применяются
  только при пустом localStorage.
- Резервные копии не содержат секретов (v3.4.7 — глубокая санация): DaData-ключ, токены источников
  (поле «Токен / ключ»), секретоподобные HTTP-заголовки (построчно), значения секретоподобных
  query-параметров url/corsProxy и вложенные поля с секретными именами исключаются из экспорта;
  обычные настройки сохраняются; восстановление копии без секретов сохраняет действующие локальные
  токены; старые копии с секретами восстанавливаются как раньше.
- Релиз v3.4.7 разделён на PUBLIC (этот публикуемый набор) и OWNER (приватный комплект владельца с
  `local-data/REAL_LEADS.json`, тестами и инструментами — НЕ публикуется) пакеты.
- Решение о возврате к встроенным реальным лидам принимает владелец: `python3 tools/embed_real_leads.py`
  собирает приватный `local-build/index.private.html` (НЕ публиковать).
- Внимание: в git-истории публичного репозитория лиды остаются (v3.4.5 и ранее). Обновление не удаляет
  историю; при необходимости её очистки — отдельное решение владельца (force-push запрещён политикой
  этого релиза).
