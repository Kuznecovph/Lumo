# Lumo 4.0 — публичная статическая сборка (GitHub Pages)

Единое приложение: интерфейс Lumo 4.0 (визуал Stage 2) + поисковый движок v3.5.3 как сервисный модуль
(без iframe, без второго поиска). Данные — в отдельном ключе localStorage `lumo4_stage3_v1`;
рабочий ключ v3.5.3 `ai_client_scout_v1` не читается и не пишется.

## Публикация

1. Распакуйте архив в папку репозитория Pages (например, `preview-v4-final/`): сохраните структуру
   `index.html`, `app/…`, `engine/…` — все пути относительные, работают из подкаталога.
2. Запушьте и включите GitHub Pages для ветки/папки — **только по решению владельца**.
3. Для работы обогащения с Pages разрешите origin в helper’е на вашем Mac:
   `LUMO_EXTRA_ORIGINS=https://<ваш-логин>.github.io local-search/start_lumo_search.command`.

## Локально без публикации

```bash
python3 -m http.server 8080 --bind 127.0.0.1   # из этой папки
# http://127.0.0.1:8080/
```

## Сервисы (без них данные НЕ имитируются)

- DaData: ключ → раздел «Данные». Без ключа — явный статус и рабочий ручной режим «JSON вручную».
- Helper 127.0.0.1:8765 и SearXNG 127.0.0.1:8888 — из поставки v3.5.3 (`local-search/`); диагностика в «Данные».

## Перенос базы из рабочей v3.5.3 (только вручную)

Рабочая Lumo → «Данные → Экспорт резервной копии» → здесь «Данные → Проверить → Импортировать / Долить без дублей».
Полная инструкция: README_RUN.md исходного пакета. Откат: не импортировать файл или вернуть прежний бэкап.
